## 📚 BIENVENUE DANS VOTRE FORMATION

### Objectifs de la Certification

Cette formation de 42 heures vous prépare à exercer la profession d'agent immobilier avec excellence. À l'issue de ce parcours, vous serez capable de :

| Compétence | Niveau visé |
|------------|-------------|
| Maîtriser le cadre juridique des transactions | ★★★★★ Expert |

| Développer votre présence digitale | ★★★★☆ Avancé |
| Conclure des transactions avec succès | ★★★★★ Expert |

1. **Révisez quotidiennement** - 30 min/jour > 3h le week-end

### 1.6 COMPROMIS VS PROMESSE VS ACTE

| Élément | Compromis de vente | Promesse de vente | Acte authentique |
|---------|-------------------|-------------------|------------------|
| **Engagement** | Réciproque et définitif | Unilatéral (vendeur) | Définitif |
| **Notaire** | Possible (conseillé) | Obligatoire | Obligatoire |
| **Délai rétractation** | 10 jours (acquéreur) | 10 jours (acquéreur) | Aucun |
| **Pénalités** | 10% du prix | 10% du prix | Selon clause |
| **Coût** | 0-500€ | Frais notaire | 7-8% ancien / 2-3% neuf |
| **Délai signature** | 2-3 mois | 2-3 mois | Immédiat |

### 1.8 COOPROPRIÉTÉ - POINTS CLÉS

| Élément | Définition | Seuil important |
|---------|------------|-----------------|
| **Tantièmes** | Parts de copropriété | Définissent quote-part charges |
| **Charges courantes** | Entretien, chauffage, eau... | Budget annuel voté en AG |
| **Charges exceptionnelles** | Gros travaux | Vote à la majorité |
| **Quote-part** | Part individuelle charges | = Tantièmes × Total charges |
| **Syndic bénévole** | Gestion par copropriétaire | Possible < 10 lots |
| **Syndic professionnel** | Gestion professionnelle | Obligatoire ≥ 10 lots |

> 📌 **À RETENIR** : Le document d'information synthétique (DIS) doit être remis à l'acquéreur en copropriété. Il résume les éléments essentiels du règlement de copropriété.

### 3.1 CAPACITÉ D'EMPRUNT - FORMULES CLÉS

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    🧮 CALCUL CAPACITÉ D'EMPRUNT                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  TAUX D'ENDETTEMENT MAXIMUM : 35% (recommandé par la HCSF)                 │
│                                                                             │
│  FORMULE PRINCIPALE :                                                       │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │   Capacité mensuelle = Revenus mensuels nets × 0,35                │   │
│  │                      - Charges mensuelles existantes               │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  EXEMPLE CALCUL :                                                           │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Revenus mensuels nets du couple : 4 500€                          │   │
│  │  Charges existantes (crédit voiture) : 250€                        │   │
│  │                                                                     │   │
│  │  Capacité mensuelle = (4 500 × 0,35) - 250                         │   │
│  │                     = 1 575 - 250                                  │   │
│  │                     = 1 325€/mois d'emprunt possible               │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  CALCUL MONTANT EMPRUNTABLE (formule mathématique) :                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                     │   │
│  │   M = C × [1 - (1 + t)^-n] / t                                     │   │
│  │                                                                     │   │
│  │   Où : M = Montant empruntable                                     │   │
│  │        C = Capacité mensuelle                                      │   │
│  │        t = Taux mensuel (taux annuel / 12)                         │   │
│  │        n = Nombre de mensualités (durée × 12)                      │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  EXEMPLE PRATIQUE :                                                         │
│  Capacité mensuelle : 1 325€                                               │
│  Taux : 3,5% sur 20 ans                                                    │
│  Montant empruntable : 1 325 × [1 - (1,0029)^-240] / 0,0029               │
│                      ≈ 227 000€                                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
