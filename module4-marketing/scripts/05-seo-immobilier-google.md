**PILIER 1 : LES MOTS-CLÉS [1 minute]**

[B-ROLL : Animation de mots-clés immobiliers]

Le SEO commence par les mots-clés. [PAUSE 2s] Ce que vos prospects tapent sur Google.

**Trois types de mots-clés**

[B-ROLL : Schéma des trois types de mots-clés]

**Les mots-clés génériques** : "agence immobilière Paris", "appartement à vendre Lyon". [PAUSE 1s] Volume élevé, concurrence forte, conversion moyenne.

**Les mots-clés longue traîne** : "agence immobilière familiale Lyon 6ème", "appartement avec terrasse vue Tour Eiffel". [PAUSE 1s] Volume plus faible, concurrence moindre, conversion excellente.

**Les mots-clés d'intention** : "estimation appartement Bordeaux", "prix m² Nantes 2026". [PAUSE 1s] L'utilisateur a une intention claire. C'est de l'or.

[B-ROLL : Outils de recherche de mots-clés]

**Outils gratuits**

Google Keyword Planner pour découvrir les volumes de recherche. [PAUSE 1s] Ubersuggest pour les suggestions de mots-clés. [PAUSE 1s] Google Trends pour identifier les tendances.

[B-ROLL : Exemple de stratégie de mots-clés]

**Stratégie recommandée**

Ciblez 5 à 10 mots-clés principaux pour votre zone géographique. [PAUSE 1s] Intégrez-les naturellement dans vos titres, descriptions et contenus. [PAUSE 1s] Ne forcez jamais. La lisibilité prime.

**PILIER 2 : L'OPTIMISATION ON-PAGE [1 minute]**

[B-ROLL : Schéma d'une page web avec éléments optimisés mis en évidence]

L'optimisation on-page, c'est tout ce que vous contrôlez directement sur votre site.

**Éléments essentiels**

[B-ROLL : Exemples de balises optimisées]

**Balise Title** : le titre qui apparaît sur Google. [PAUSE 1s] Maximum 60 caractères. [PAUSE 1s] Incluez votre mot-clé principal. [PAUSE 1s] Exemple : "Agence Immobilière Lyon 6 | Vente & Estimation | Votre Agence".

**Meta-description** : le résumé sous le titre. [PAUSE 1s] Maximum 160 caractères. [PAUSE 1s] Doit inciter au clic. [PAUSE 1s] Exemple : "Votre agence immobilière de confiance à Lyon 6ème. Estimation gratuite, mandats exclusifs. Découvrez nos biens de charme et contactez nos experts."

**Balises H1, H2, H3** : structurez votre contenu. [PAUSE 1s] Une seule H1 par page. [PAUSE 1s] H2 pour les sections principales. [PAUSE 1s] H3 pour les sous-sections.

**URL optimisées** : courtes, descriptives, avec mots-clés. [PAUSE 1s] "votresite.com/agence-immobiliere-lyon" plutôt que "votresite.com/page?id=12345".

[B-ROLL : Exemple de page parfaitement optimisée]

**Images optimisées**

Nommez vos images descriptivement. [PAUSE 1s] "appartement-terrasse-vue-lyon.jpg" plutôt que "IMG_1234.jpg". [PAUSE 1s] Remplissez les balises ALT. [PAUSE 1s] Compressez les images pour la vitesse de chargement.

**PILIER 4 : LE NETLINKING [1 minute]**

[B-ROLL : Schéma de liens entrants vers un site]

Le netlinking, ce sont les liens d'autres sites vers le vôtre. [PAUSE 2s] C'est un signal de confiance majeur pour Google.

**Types de liens**

[B-ROLL : Exemples de sources de backlinks]

**Liens locaux** : mairie, office de tourisme, associations locales. [PAUSE 1s] Demandez un lien vers votre site. [PAUSE 1s] Offrez un contenu de valeur en échange.

**Liens professionnels** : partenaires (notaires, banques, artisans), fédérations professionnelles, médias spécialisés.

**Liens de presse** : articles, interviews, communiqués. [PAUSE 1s] Chaque mention dans la presse est une opportunité de backlink.

**Liens sociaux** : profils LinkedIn, Facebook, Instagram. [PAUSE 1s] Ils renforcent votre présence digitale globale.

[B-ROLL : Graphique de la pyramide de liens]

**Qualité avant quantité**

Un lien d'un site prestigieux vaut mieux que dix liens de sites médiocres. [PAUSE 2s] Concentrez-vous sur la qualité des liens entrants.
