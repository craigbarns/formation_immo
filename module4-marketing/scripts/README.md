## 🎬 GUIDE DE PRODUCTION

### Étapes de Production

1. **Préparation**
   - Choisir la voix ElevenLabs
   - Générer les visuels Midjourney
   - Préparer le studio d'enregistrement

2. **Enregistrement**
   - Suivre le script segment par segment
   - Respecter les pauses marquées
   - Maintenir le ton recommandé

3. **Montage**
   - Intégrer les B-roll selon les indications
   - Ajouter la musique de fond (20% du volume)
   - Vérifier la synchronisation

4. **Post-production**
   - Ajouter les transitions
   - Intégrer les graphiques animés
   - Vérifier la qualité audio

### Ratio Voix/Musique
- Voix : 80%
- Musique : 20%

### Format de Sortie
- Ratio : 16:9 (paysage)
- Résolution : 1080p minimum
- Format : MP4 (H.264)
