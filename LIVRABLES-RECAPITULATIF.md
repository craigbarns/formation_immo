**Thèmes couverts :**

**Cas pratiques :** 45 rue de Sèze (Lyon), 25 rue de la République (Lyon)

## 🎬 PRODUCTION VIDÉO

### Spécifications des scripts
- **Durée** : 8-10 minutes par vidéo
- **Format** : Accroche → Problématique → Contenu → Cas pratique → Conclusion
- **B-roll** : Indications détaillées pour chaque segment
- **Pauses** : Marquées [PAUSE Xs] pour le rythme
- **Voix** : Recommandations ElevenLabs avec paramètres

- **25 vidéos** × 9 min = **~4 heures de contenu**
- **~38 000 mots** de scripts

## 🚀 PROCHAINES ÉTAPES

### Pour déployer la formation :
1. ✅ Vérifier la conformité juridique avec votre expert
2. ✅ Adapter les templates avec votre logo et coordonnées
3. ✅ Préparer le matériel de formation (salle, vidéoprojecteur)
4. ✅ Imprimer le Guide de l'élève (30 pages)
5. ✅ Tester les QCM avec un groupe pilote
6. 🎬 Produire les vidéos (option e-learning)
7. 📅 Planifier les sessions selon le calendrier type

### Pour la production vidéo :
1. Sélectionner les scripts par module
2. Générer les visuels avec Midjourney (prompts fournis)
3. Enregistrer les voix sur ElevenLabs (recommandations fournies)
4. Monter les vidéos sur HeyGen/Synthesia (storyboards fournis)
5. Intégrer les B-roll selon les indications
