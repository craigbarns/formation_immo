## 🎬 VIDÉO 1 : LA VISITE DU TERRAIN
**Durée estimée : 2 minutes 30 secondes**

### PLAN 1 - Introduction (0:00-0:15)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan moyen (taille) |
| **Description visuelle** | Avatar se tenant sur le terrain vacant, habillé professionnellement, souriant confiant, geste d'accueil vers le terrain |
| **Arrière-plan IA** | Terrain vide avec bornes de délimitation visibles, paysage français typique, ciel bleu |
| **Texte à dire** | *"Bienvenue sur ce terrain de 800m². Aujourd'hui, je vais vous montrer comment transformer une simple visite en opportunité concrète."* |
| **B-roll** | Plans larges du terrain, détails des bornes, vue d'ensemble du quartier |
| **Musique** | Ambiance légère, corporate positive |

### PLAN 2 - La Préparation (0:15-0:45)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan rapproché (poitrine) |
| **Description visuelle** | Avatar tenant un dossier technique, pointant des documents, expression professionnelle |
| **Arrière-plan IA** | Table avec plans, documents, tablette numérique posée |
| **Texte à dire** | *"Avant la visite, je vérifie toujours trois éléments essentiels : le bornage, le PLU, et les réseaux. Cette préparation montre votre professionnalisme et rassure vos clients."* |
| **B-roll** | Gros plans sur documents, plans cadastraux, tablette affichant informations |
| **Motion** | Apparition de check-list visuelle à l'écran |

### PLAN 3 - La Découverte (0:45-1:30)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan américain (mi-cuisse) |
| **Description visuelle** | Avatar marchant sur le terrain, gestes ouverts, montrant les différentes zones |
| **Arrière-plan IA** | Terrain avec perspectives, points de repère naturels, orientation sud visible |
| **Texte à dire** | *"Pendant la visite, faites marcher vos clients sur le terrain. Montrez-leur l'orientation, les points de vue, imaginez avec eux l'emplacement de leur future maison. Un terrain, c'est du potentiel qu'il faut savoir faire rêver."* |
| **B-roll** | Vues panoramiques, détails du terrain, simulation 3D maison future |
| **Motion** | Flèches indiquant orientation, zones constructibles |

### PLAN 4 - Les Objections (1:30-2:00)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan rapproché (poitrine) |
| **Description visuelle** | Avatar à l'écoute, expression empathique, hochements de tête |
| **Arrière-plan IA** | Espace neutre, ambiance conversation |
| **Texte à dire** | *"Les clients exprimeront des doutes : 'C'est loin des commerces', 'Le terrain est en pente'... Chaque objection est une opportunité. Reformulez positivement : 'Vous aurez la tranquillité' ou 'La pente offre une vue dégagée'."* |
| **B-roll** | Exemples visuels : commerces à proximité, terrassement réussi |
| **Motion** | Bulles de dialogue avec réponses positives |

### PLAN 5 - Conclusion (2:00-2:30)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan moyen (taille) |
| **Description visuelle** | Avatar concluant, geste de poignée de main virtuelle, sourire chaleureux |
| **Arrière-plan IA** | Terrain avec perspective de construction, optimiste |
| **Texte à dire** | *"Une visite réussie ne se termine pas sur le terrain. Proposez immédiatement une suite : un rendez-vous au bureau pour étudier les plans. Créez le momentum."* |
| **B-roll** | Transition vers bureau moderne, documents sur table |
| **Musique** | Montée en intensité, conclusion positive |
| **CTA** | *"Passons maintenant à l'argumentaire terrain."* |

| **B-roll** | Exemples de réponses, clients rassurés |
