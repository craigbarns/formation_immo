## 📊 SYNTHÈSE MODULE 5

### Thématique
La vente de terrain en 5 étapes : Visite → Argumentaire → Closing → Signature → Fidélisation

### Public Cible
Agents immobiliers, négociateurs, conseillers terrain

### Objectif Pédagogique
Maîtriser le cycle complet de vente terrain, de la première visite à la recommandation client

---

## 🚀 PROCHAINES ÉTAPES SUGGÉRÉES

1. **Génération images** : Utiliser les prompts Midjourney pour créer les arrière-plans
2. **Enregistrement voix** : Sélectionner et tester la voix ElevenLabs
3. **Production vidéo** : Assembler avatar + voix + images selon storyboards
4. **Motion design** : Ajouter animations et éléments graphiques
5. **Montage final** : Intégrer B-roll et musique

## 📞 NOTES POUR L'ÉQUIPE DE PRODUCTION

### Points d'Attention
- Maintenir la cohérence visuelle entre les 5 vidéos
- Respecter la durée totale de 12'30" pour engagement optimal
- Privilégier la voix masculine senior pour crédibilité terrain
- Tester les prompts Midjourney avant production en masse

### Ressources Externes Nécessaires
- Accès Midjourney V6
- Compte ElevenLabs Pro
- Banque d'images B-roll (terrains, constructions, signatures)
- Musique libre de droits (ambiance corporate)
