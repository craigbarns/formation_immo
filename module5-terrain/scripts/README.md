## 📋 STRUCTURE DES SCRIPTS

Chaque script contient:

1. **Métadonnées techniques**
   - Durée estimée
   - Nombre de mots
   - Voix ElevenLabs recommandée
   - Rythme et ambiance musicale

2. **Prompt Midjourney** pour le visuel principal

3. **Script complet** avec:
   - Accroche (30-40 secondes)
   - Problématique (60-80 secondes)
   - Contenu structuré en phases/techniques
   - Cas pratique avec vraies adresses
   - Conclusion avec plan d'action

4. **Indications B-roll** entre [crochets]

5. **Pauses** [PAUSE Xs] pour le rythme

6. **Notes de production** avec timing détaillé et suggestions musicales
