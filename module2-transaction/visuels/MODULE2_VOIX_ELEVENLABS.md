## 🔧 GUIDE D'UTILISATION ELEVENLABS

### Étapes de génération

1. **Connexion** : Accédez à https://elevenlabs.io
2. **Sélection voix** : Entrez l'ID de voix dans le champ Voice ID
3. **Paramètres** : Appliquez les réglages suggérés ci-dessus
4. **Texte** : Copiez-collez le script du storyboard
5. **Génération** : Cliquez sur "Generate"
6. **Téléchargement** : Exportez en MP3 ou WAV

### Astuces d'optimisation

| Astuce | Description |
|--------|-------------|
| **Pauses** | Ajoutez des `...` pour des pauses naturelles |
| **Emphase** | Utilisez des **mots** pour marquer l'importance |
| **Chiffres** | Écrivez les chiffres en lettres pour meilleure fluidité |
| **Paragraphes** | Séparez en blocs de 3-4 phrases maximum |
| **Test** | Générez un extrait avant le script complet |

### Format de script optimisé

```
[Plan 1]
Bonjour et bienvenue dans cette formation sur l'estimation immobilière.
Aujourd'hui, je vais vous révéler les méthodes professionnelles pour évaluer précisément la valeur d'un bien immobilier.

[Plan 2]
Une estimation précise est la pierre angulaire de votre succès.
Trop haute, votre mandat ne vendra pas.
Trop basse, vous dévaloriserez le patrimoine de votre client.
L'équilibre est essentiel.
```
