## 🎬 STRUCTURE COMMUNE DES SCRIPTS

Chaque script contient :

### 1. En-tête technique
- Durée et nombre de mots
- Voix ElevenLabs recommandée
- Description de l'avatar
- Prompt Midjourney pour le visuel d'accompagnement

### 2. Script narratif (5 segments)
- **ACCROCHE** (45-50s) : Captiver l'attention avec une statistique frappante
- **PROBLÉMATIQUE** (60s) : Identifier le pain point du spectateur
- **CONTENU STRUCTURÉ** (4-5 min) : Méthode en étapes avec techniques concrètes
- **CAS PRATIQUE** (1m30-2min) : Exemple réel avec adresses lyonnaises authentiques
- **CONCLUSION** (60s) : Récapitulatif + call-to-action actionnable

### 3. Éléments de production
- **B-ROLL** : Indications détaillées entre [crochets] pour chaque segment
- **PAUSES** : [PAUSE 2s] pour le rythme de parole
- **FICHE TECHNIQUE** : Récapitulatif en fin de document
- **POINTS CLÉS** : Takeaways essentiels à retenir
