# PLAN PÉDAGOGIQUE GLOBAL
## Formation Agent Immobilier - Certification Professionnelle

---

# 1. PRÉSENTATION GÉNÉRALE

## Titre de la formation
**Formation Agent Immobilier - Certification Professionnelle 42h**
*Devenir un professionnel compétent et conforme de l'immobilier*

## Public cible
| Profil | Description | Motivation |
|--------|-------------|------------|
| **Futurs agents** | Personnes souhaitant intégrer le métier d'agent immobilier | Obtenir les bases pour démarrer |
| **Reconversion** | Professionnels d'autres secteurs cherchant une nouvelle carrière | Changer de métier avec méthode |
| **Perfectionnement** | Agents débutants souhaitant consolider leurs compétences | Améliorer leurs pratiques quotidiennes |
| **Entrepreneurs** | Futurs créateurs d'agence immobilière | Maîtriser tous les aspects du métier |

## Prérequis
- Aucun prérequis technique obligatoire
- Niveau de français : B2 minimum
- Compétences de base en mathématiques (calculs simples)
- Maîtrise de l'outil informatique (niveau débutant suffisant)
- Motivation et appétence pour le secteur immobilier

## Objectifs globaux de la formation

À l'issue de cette formation de 42 heures, le participant sera capable de :

| Objectif | Description | Niveau Bloom |
|----------|-------------|--------------|
| OG1 | Maîtriser le cadre juridique de la transaction immobilière | Comprendre/Appliquer |
| OG2 | Conduire une transaction de A à Z avec professionnalisme | Appliquer/Analyser |
| OG3 | Calculer et négocier les financements immobiliers | Appliquer/Analyser |
| OG4 | Développer une stratégie marketing digital efficace | Créer/Évaluer |
| OG5 | Acquérir et valoriser des terrains à bâtir | Appliquer/Analyser |
| OG6 | Respecter la déontologie et la conformité réglementaire | Comprendre/Appliquer |
