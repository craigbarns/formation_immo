# PLAN PÉDAGOGIQUE DÉTAILLÉ - MODULE 1 : JURIDIQUE

## Formation Professionnelle Immobilière
**Durée totale : 10 heures (8h formation + 2h évaluation)**

---

## 📋 INFORMATIONS GÉNÉRALES

| Élément | Description |
|---------|-------------|
| **Module** | Module 1 - Juridique |
| **Durée** | 10h (8h formation + 2h évaluation) |
| **Public cible** | Agents immobiliers, négociateurs, conseillers en immobilier |
| **Niveau** | Intermédiaire à avancé |
| **Format** | Présentiel + ressources e-learning |

---

## 🎯 PRÉREQUIS

Avant de suivre ce module, le participant doit :
- Avoir suivi la formation initiale de l'EI (ou équivalent)
- Connaître les bases du droit civil (contrats, obligations)
- Maîtriser le vocabulaire immobilier fondamental
- Disposer d'une expérience minimale de 6 mois en transaction ou location

---

## 🏆 ACQUIS VISÉS

À l'issue de ce module, le participant sera capable de :
1. **Appliquer** les dispositions de la loi ALUR dans sa pratique quotidienne
2. **Rédiger** un compromis de vente sécurisé et conforme
3. **Interpréter** et **exploiter** les diagnostics immobiliers obligatoires
4. **Conseiller** le vendeur sur le choix du mandat adapté
5. **Analyser** les documents de copropriété et calculer les charges
6. **Établir** un état des lieux conforme et un bail location sécurisé
