## 🎯 SPÉCIFICATIONS TECHNIQUES

### Visuels
- **Format** : 1920×1080 (Full HD)
- **Ratio** : 16:9
- **Débit** : 8-12 Mbps
- **Codec** : H.264

### Audio
- **Format** : AAC 48kHz
- **Volume** : -16 LUFS (normalisé)
- **Musique** : -20dB sous la voix

### Livraison
- **Format** : MP4
- **Qualité** : 1080p
- **Sous-titres** : SRT optionnel

---

## 📞 NOTES POUR L'ÉQUIPE

### Cohérence Visuelle
- Utiliser la même palette de couleurs sur toutes les vidéos
- Maintenir un style d'avatar cohérent
- Uniformiser la typographie

### Cohérence Audio
- Même niveau sonore sur toutes les vidéos
- Musique de fond cohérente
- Transitions audio fluides

### Accessibilité
- Prévoir les sous-titres
- Contraste suffisant pour le texte
- Débit de parole adapté (130-150 mots/min)
