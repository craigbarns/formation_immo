## 🎯 Structure Commune à Tous les Scripts

Chaque script suit la même structure pédagogique :

1. **Accroche (30s)** : Captiver l'attention avec une situation problématique
2. **Problématique (1min)** : Chiffrer l'enjeu et la nécessité de formation
3. **Contenu structuré (6-7min)** : Découper en 3-4 parties thématiques
4. **Cas pratique réaliste (1min)** : Situation concrète avec adresse parisienne réelle
5. **Conclusion actionnable (30s)** : 3 actions immédiates à mettre en œuvre

---

## 📝 Éléments Techniques Communs

### Indications B-roll
- Entre crochets `[B-ROLL : description]`
- Placés avant chaque segment de narration
- Durée indicative de 5 secondes par indication

### Pauses
- `[PAUSE 1s]` ou `[PAUSE 2s]` pour le rythme
- Essentielles pour la compréhension et l'impact

### Références Juridiques
- Articles de loi précis (Code civil, Code de la construction)
- Décrets 2024-2026
- Arrêtés réglementaires

### Exemples Concrets
- Vraies adresses parisiennes
- Montants réalistes
- Situations professionnelles authentiques
