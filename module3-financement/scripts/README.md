## 🎯 Points Clés du Module 3

### Crédit
- Taux 2026 : 3,2-3,8% sur 20 ans
- Taux d'usure à vérifier impérativement
- Assurance déléguable à tout moment
- Apport : 15-20% quasi-indispensable

### Fiscalité
- Frais notaire : 7-8% ancien, 2-3% neuf
- Micro-foncier : abattement 30%
- Plus-value : exonération progressive 22-30 ans
- Taxe foncière : 2-3 mois de loyer

### Rentabilité
- Toujours calculer la rentabilité net-net
- Intégrer TOUS les coûts réels
- Cash-flow = indicateur de viabilité mensuelle
- TRI = indicateur complet long terme

### Dispositifs Fiscaux
- Pinel : 10,5%-17,5% selon durée
- Denormandie : travaux >25% obligatoires
- LMNP : abattement 50% sur meublé
- Adapter au profil et objectifs du client

### Assurances
- PNO obligatoire pour propriétaire bailleur
- Assurance emprunteur négociable (loi Lemoine)
- GLI : 2-4% du loyer annuel
- DO obligatoire pour construction >100K€
