### 🎬 PLAN 2 - RENTABILITÉ BRUTE (0:30-1:00)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan moyen formule |
| **Visuel IA** | Formule mathématique élégante : (Loyers annuels / Prix d'achat) × 100, design type présentation TED, fond sombre avec éléments colorés |
| **Texte à dire** | "Commençons par la rentabilité brute. C'est le ratio le plus simple : vos loyers annuels divisés par le prix d'achat du bien, le tout multiplié par 100. Elle donne une première idée mais ne suffit pas à elle seule." |
| **B-Roll** | Animation de la formule avec exemple chiffré |
| **Musique** | Clair et explicatif |

---

### 🎬 PLAN 3 - RENTABILITÉ NETTE (1:00-1:45)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan moyen schéma |
| **Visuel IA** | Schéma en cascade montrant les charges qui se déduisent des loyers, design infographique moderne, couleurs par type de charge |
| **Texte à dire** | "La rentabilité nette est plus réaliste. Elle déduit du loyer toutes les charges : crédit, taxe foncière, copropriété, assurance, travaux, vacance locative, gestion. C'est votre vrai rendement avant impôt." |
| **B-Roll** | Animation : loyer brut → déduction charges → loyer net |
| **Musique** | Progression méthodique |

---

### 🎬 PLAN 4 - RENTABILITÉ NETTE NETTE (1:45-2:30)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan rapproché calcul |
| **Visuel IA** | Calculatrice avec opérations en cours, feuille Excel avec formules, mise au point sur le résultat final |
| **Texte à dire** | "La rentabilité nette nette, c'est l'indicateur ultime. Elle intègre l'imposition sur vos revenus fonciers. C'est ce qui reste réellement dans votre poche. Un investissement à 3% net net peut être excellent si l'endettement est faible." |
| **B-Roll** | Comparaison visuelle des 3 rentabilités sur même exemple |
| **Musique** | Accent sur le résultat final |

### 🎬 PLAN 5 - CASH-FLOW (2:30-3:15)
| Élément | Description |
|---------|-------------|

| **Texte à dire** | "Le cash-flow mensuel est crucial pour votre budget. C'est la différence entre le loyer perçu et la mensualité de crédit. Un cash-flow positif vous génère des revenus complémentaires. Négatif, il vous coûte chaque mois mais peut être stratégique pour la défiscalisation." |
| **B-Roll** | Animation du cash-flow positif vs négatif avec conséquences |
