## 📝 CONSEILS DE RÉDACTION POUR ELEVENLABS

### Ponctuation :
- Utiliser des virgules pour les pauses naturelles
- Points pour marquer les fins de phrases courtes
- Points de suspension pour les suspensions...
- Deux-points avant les listes :

### Phonétique :
- "Taux" → bien articuler le [o]
- "Net net" → insister sur la distinction
- Chiffres → "deux virgule cinq pour cent" plutôt que "2,5%"
- Acronymes → épeler LMNP, PTIA, ITT, IPT

### Rythme :
- Phrases de 15-20 mots maximum
- Pauses après les chiffres clés
- Variation de ton sur les points importants
- Ralentir sur les avertissements
