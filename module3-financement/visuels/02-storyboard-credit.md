# STORYBOARD VIDÉO 1 : LE CRÉDIT IMMOBILIER
## Module 3 - Financement | Durée estimée : 4-5 minutes

---

### 🎬 PLAN 1 - INTRODUCTION (0:00-0:30)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan large d'accueil |
| **Visuel IA** | Bureau bancaire moderne avec vue panoramique, documents de prêt sur le bureau, calculatrice, ambiance professionnelle chaleureuse |
| **Texte à dire** | "Bienvenue dans ce module consacré au crédit immobilier, le levier financier indispensable de l'investissement locatif. Aujourd'hui, nous allons décrypter ensemble les mécanismes du prêt pour optimiser votre financement." |
| **B-Roll** | Zoom progressif sur les documents de prêt, transition vers graphique animé |
| **Musique** | Ambiance corporate légère, intro dynamique |

---

### 🎬 PLAN 2 - LES BASES DU CRÉDIT (0:30-1:15)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan moyen + infographie |
| **Visuel IA** | Mains tenant un document de simulation de prêt, chiffres clés en surbrillance, fond flou bureau bancaire |
| **Texte à dire** | "Le crédit immobilier fonctionne sur trois piliers : le capital emprunté, le taux d'intérêt et la durée de remboursement. Comprendre leur interaction est essentiel pour négocier les meilleures conditions." |
| **B-Roll** | Animation des 3 piliers : montant, taux, durée - schéma interactif |
| **Musique** | Continue, rythmée mais discrète |

---

### 🎬 PLAN 3 - LE TAUX D'INTÉRÊT (1:15-2:00)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan rapproché + data viz |
| **Visuel IA** | Courbe d'évolution des taux sur écran, graphique 3D avec variations colorées, interface fintech moderne |
| **Texte à dire** | "Le taux d'intérêt est le coût de votre emprunt. Un écart de seulement 0,5% sur 20 ans peut représenter des milliers d'euros d'économies. Surveillez les tendances et négociez systématiquement." |
| **B-Roll** | Comparaison visuelle : 2% vs 2,5% sur 200 000€ - barres animées |
| **Musique** | Accentuation légère sur les chiffres clés |

---

### 🎬 PLAN 4 - L'APPORT PERSONNEL (2:00-2:45)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan moyen conceptuel |
| **Visuel IA** | Balance équilibrée avec pièces d'un côté et maison miniature de l'autre, fond neutre élégant, symbole de l'équilibre financier |
| **Texte à dire** | "L'apport personnel sécurise votre dossier et réduit le coût total du crédit. 10% du prix d'achat est un minimum recommandé, mais 20% ouvrent les meilleures conditions de financement." |
| **B-Roll** | Animation de la balance qui s'équilibre, pourcentages qui apparaissent |
| **Musique** | Transition douce |

---

### 🎬 PLAN 5 - L'ASSURANCE EMPRUNTEUR (2:45-3:30)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan rapproché document |
| **Visuel IA** | Contrat d'assurance emprunteur avec main signature, tampon officiel visible, mise au point sur les garanties essentielles |
| **Texte à dire** | "L'assurance emprunteur protège votre famille et votre banque. Décès, invalidité, perte d'emploi : choisissez les garanties adaptées à votre situation. Depuis la loi Lemoine, vous pouvez résilier à tout moment pour trouver mieux." |
| **B-Roll** | Icônes des 3 garanties qui apparaissent séquentiellement |
| **Musique** | Légère tension puis résolution |

---

### 🎬 PLAN 6 - NÉGOCIER SON PRÊT (3:30-4:00)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan moyen dynamique |
| **Visuel IA** | Réunion de négociation, deux personnes face à face avec documents, atmosphère professionnelle constructive, éclairage chaleureux |
| **Texte à dire** | "La négociation est un jeu d'échec. Préparez votre dossier, comparez les offres, faites jouer la concurrence. Chaque point de négocié sur le taux ou les frais de dossier compte pour votre rentabilité." |
| **B-Roll** | Split-screen : offre A vs offre B, différenciation visuelle |
| **Musique** | Rythme qui s'intensifie légèrement |

---

### 🎬 PLAN 7 - CAS PRATIQUE (4:00-4:45)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan large tableau de bord |
| **Visuel IA** | Écran d'ordinateur avec simulateur complet, tableau d'amortissement détaillé, mensualités et coût total visibles |
| **Texte à dire** | "Prenons un exemple concret : 200 000 euros empruntés sur 20 ans à 3,5%. Vos mensualités s'élèvent à 1 160 euros pour un coût total du crédit de 78 400 euros. Avec 1% de moins, vous économisez plus de 22 000 euros." |
| **B-Roll** | Animation du tableau d'amortissement, mise en évidence des économies |
| **Musique** | Accentuation sur le chiffre final |

---

### 🎬 PLAN 8 - CONCLUSION (4:45-5:00)
| Élément | Description |
|---------|-------------|
| **Type de plan** | Plan large de sortie |
| **Visuel IA** | Retour au bureau bancaire initial, documents rangés, ambiance de réussite, lumière dorée de fin de journée |
| **Texte à dire** | "Le crédit immobilier est votre allié pour investir. Maîtrisez ses mécanismes, négociez intelligemment, et vous transformerez la dette en levier de création de patrimoine. À vous de jouer !" |
| **B-Roll** | Logo formation + call-to-action visuel |
| **Musique** | Outro positive et motivante |
